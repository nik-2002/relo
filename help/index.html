Overview

Relo is a super-minimal menu bar timer for macOS. It’s keyboard-driven, supports natural-language input, and intentionally focuses on a single active timer to keep the interface uncluttered. Relo uses macOS system colors and adapts automatically to light or dark mode. Shortcuts and alerts are configurable.

Relo does not track or collect data.

Installation

Requires macOS 14 or later.

Private build

Relo is currently distributed as a private macOS build and does not update automatically.

  1. Open Relo.dmg.
  2. Drag Relo to your Applications folder.
  3. Launch Relo. It appears in the menu bar.
  4. macOS may prompt you to add Relo to your login items. You can change this later in Relo Settings or System Settings → General → Login Items & Extensions.

Basic usage

Relo supports two timekeeping modes.

  • Countdown — run a timer for a set duration.
  • Stopwatch — count up from zero.

Countdown

Start a timer by typing a duration into the Relo popover. Relo accepts flexible, natural inputs like these:

  • 10, 10m, 10 min → 10-minute timer.
  • 1h 30m, 1.5 hours → 1-hour 30-minute timer.
  • 45s, 45 seconds, :45 → 45-second timer.
  • You can also count down to a specific time: 6:15 am, 615a.

Press Return to start. The active timer replaces any existing one. Duration timers count down to zero, then play the configured alarm tone.

Finished timers can be repeated or cleared from the popover.

Stopwatch

Start a stopwatch in a few ways:

  • Click the play button in the Relo popover.
  • Click Stopwatch in the context menu.
  • Type sw or stopwatch into the Relo popover and press Return.

Stopwatch timers count up indefinitely until paused or cleared.

Context menu

  • Access controls by right-clicking the menu bar icon.
  • Start a stopwatch timer.
  • Pause or clear a timer.
  • Repeat the last timer (option visible when a timer has finished).
  • Access Settings.
  • Access the About Relo panel.
  • Quit Relo.

Settings

  • Launch Relo at Login — start Relo automatically when you sign in.
  • Play Sound — play or silence the completion alert.
  • Tone — choose from four bundled Relo sounds and preview the selection with the play button.
  • Custom Tone — import an audio file, replace it later, or remove Relo’s private copy without changing the original file.
  • Repeat — control how many times the alert plays.
  • Volume — control alert loudness.
  • Default Unit — choose the unit used for bare numbers.
  • Timer Presets — type an exact duration from 1 to 1,440 minutes or use the steppers to adjust three distinct one-click timers.
  • Show/Hide Relo — configure the global shortcut to toggle the popover.
  • Pause/Resume — configure the global shortcut to toggle the active timer.
  • Clear Timer — configure the global shortcut to stop and clear the timer.

Keyboard shortcuts

All shortcuts are configurable in Settings.

  • Show/Hide Relo — ⌃⌥⌘R
  • Pause/Resume — ⌃⌥⌘P
  • Clear Timer — ⌃⌥⌘X

Bugs & crashes

If you run into a bug or unexpected behavior, report it to the person who provided the private build and include your macOS version, Relo version, and any relevant details.

Privacy

Relo does not collect, store, or share personal data. There are no accounts, analytics, or tracking. For details, see the privacy policy.
